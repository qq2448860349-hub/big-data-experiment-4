# 实验四报告记录

实验题目可写 Apriori频繁项集挖掘的单机与Spark并行实现。

实验目的、环境、原理、步骤、结论与体会及1至3道问答沿用课程模板。

数据应写自行生成的30000笔教学购物篮、12种商品、种子20261118，具体校验值从 data/manifest.json 抄录。说明生成数据的购买组合和随机加入商品方式。

运行后从 serial.json、spark.json 抄录有效交易数、阈值、各层候选及频繁项集数量、运行耗时。spark.json 的 application_id 和 master 对应本次真实 YARN 应用。

结果从本次 serial.tsv、spark.tsv 抄录。保留至少几条多商品频繁组合的真实次数。粘贴 MATCH 和输出 SHA256，说明逐项及文件字节比较结果。没有显示 MATCH 时先排错。
